# Backlog

## Add a scripts folder to every exported project

Create a `scripts/` folder inside each exported project's root, alongside its
existing export folders, for project-specific scripts.

## Shorten border-highlight child-node labels

Remove the `$countryShotName_Border` prefix from the labels of child nodes
inside `$countryShotName_Border_Highlight_Group`. Keep the group label unchanged.
This is a label cleanup only: preserve node connections and animation. If the
implementation also changes internal node IDs, update all references safely.

## Add an unkeyframed editing camera to the 3D map scene

Connect two cameras to `map_3d_scene`. The first retains the default camera
movement generated by the app and remains the camera used for export. The
second has no keyframes and is used only while editing to preview the map and
objects from different angles. Switching to or repositioning the editing
camera must not change the generated camera's animation or the default export.

## Rebuild map assets without replacing manual Fusion work

The animation editor should be able to analyze an updated camera path and
regenerate only the affected Wide, Detail, and Close-up imagery and matching
mask assets. Existing Fusion compositions may contain substantial manual work,
so rebuilding assets must preserve node names, paths, styling, timing, and
unrelated user-created nodes.

Acceptance criteria:

- Detect which existing image levels no longer cover the edited camera path or
  no longer meet the configured resolution threshold.
- Regenerate only affected assets, using stable filenames and geographic
  extents where possible.
- Relink or update generated Fusion nodes without replacing unrelated or
  manually edited nodes.
- Create backups before modifying a composition.
- Report movements that exceed the rebuilt coverage margin and require a new
  Close-up level.

This is follow-up work. The initial adaptive-resolution implementation may
generate a new composition after camera movement is finalized.
