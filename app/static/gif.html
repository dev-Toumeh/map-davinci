Turn a GIF into an editable Fusion group that keeps looping, with its original timing and transparency.

This folder applies to future GIF exports. Existing packages stay in place.

Fusion group ready

Download setting Download package

Drag the .setting into Fusion. It contains one looping GIF layer in a MultiMerge over a transparent 3840 × 2160 canvas. Use Position, Size, and Angle to place it; Canvas width and height change the output dimensions.

Match Timeline FPS to your composition; Speed 1 uses the original timing, and Offset changes the starting phase.

Keep the exported PNG folder in place. The setting references those files. If you move the package or use another computer, open the group and relink its Loader to Frames/frame_0000.png.
